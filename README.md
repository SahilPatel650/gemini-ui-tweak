# Gemini UI Tweak

A Chromium extension that moves the **Temporary Chat** button from Google Gemini's sidebar into the main chat interface whenever a new (empty) chat is open.

## Why?

In Google Gemini the "Temporary Chat" option lives in the sidebar — easy to miss and a bit out of the way. When you open a fresh chat it makes more sense to have that toggle right where you are: near the text input, so you can quickly choose whether the conversation should be saved before you start typing.

## What it does

| Without extension | With extension |
|---|---|
| Temporary Chat button visible only in the sidebar | Temporary Chat button is **moved** into the main chat area (above the text input) on a new-chat view |
| – | Sidebar button is **hidden** to avoid duplication |
| – | When you navigate to an existing conversation the button is **restored** to the sidebar automatically |

## Installation (Developer mode)

1. Clone / download this repository.
2. Open Chrome (or any Chromium-based browser) and go to `chrome://extensions`.
3. Enable **Developer mode** (toggle in the top-right corner).
4. Click **Load unpacked** and select the root folder of this repository.
5. Navigate to [gemini.google.com](https://gemini.google.com) — the extension activates automatically.

## How it works

`content.js` is injected on every `gemini.google.com` page and:

1. **Detects the new-chat view** — checks the URL path and the absence of conversation-turn elements.
2. **Locates the sidebar button** — tries several selector strategies (aria-label, `data-test-id`, Material icon names, text-node scan) to handle Gemini UI updates gracefully.
3. **Clones the button** into a wrapper `<div>` positioned above the main text-input container, and **hides** the original sidebar entry.
4. **Forwards clicks** on the clone to the original element so Gemini's own state management continues to work.
5. **Restores everything** when the user navigates to an existing conversation.

A `MutationObserver` + History API interception ensures the extension reacts correctly to Gemini's React-driven SPA navigation.

## Files

```
manifest.json   — Extension manifest (Manifest V3)
content.js      — Core DOM manipulation logic
styles.css      — Hides the sidebar button; styles the injected clone
icons/          — Extension icons (16 × 16, 48 × 48, 128 × 128 PNG)
README.md       — This file
```

## Compatibility

Tested against the Gemini web interface as of early 2025. Because Gemini's DOM is generated by a JavaScript framework the extension uses multiple fallback selectors, so it should survive minor UI updates. If Gemini makes a significant structural change you may need to update the selectors in `content.js`.
